Privacy Policy

Last updated: November 12, 2026 · Deutsche Version

Summary

TableDrop does not collect, transmit or sell any data. There are no accounts, no analytics and no servers operated by us.

What the extension accesses

Only when you click the TableDrop icon, the extension gets temporary access to the current tab (Chrome's "activeTab" permission). It reads the tables on that page to show them in the list and to create the copy or file you ask for. It has no access to other tabs or websites and does not run in the background.

What happens with the table data

Table contents are processed in your browser only. When you click Copy or MD, the table is placed on your clipboard. When you click CSV or Excel, a file is created on your computer. Nothing is sent to us or to any third party, and table contents are not stored by the extension.

What is stored

Only your CSV format setting (automatic, comma or semicolon), saved locally in your browser with chrome.storage.local. Uninstalling the extension removes it.

Permissions

  • activeTab: temporary access to the current tab after you click the icon
  • scripting: to run the table detection in that tab and highlight a table
  • storage: to save your CSV format setting

This website

This website is hosted on GitHub Pages (GitHub Inc., USA). When you visit it, GitHub may process technical data such as your IP address to deliver the page. See the GitHub Privacy Statement. We do not use cookies or analytics on this website.

Changes

If future versions process data differently (for example license checks for paid features), this policy will be updated before those versions are released.

Datenschutzerklärung

Stand: 12. November 2026

Kurzfassung

TableDrop erhebt, überträgt und verkauft keine Daten. Es gibt keine Konten, keine Analyse-Tools und keine von uns betriebenen Server.

Worauf die Erweiterung zugreift

Nur wenn du auf das TableDrop-Symbol klickst, erhält die Erweiterung vorübergehend Zugriff auf den aktuellen Tab (Chrome-Berechtigung „activeTab“). Sie liest die Tabellen dieser Seite, um sie in der Liste anzuzeigen und die gewünschte Kopie oder Datei zu erstellen. Auf andere Tabs oder Websites hat sie keinen Zugriff, und sie läuft nicht im Hintergrund.

Was mit den Tabellendaten passiert

Tabelleninhalte werden ausschließlich in deinem Browser verarbeitet. Bei „Kopieren“ oder „MD“ landet die Tabelle in deiner Zwischenablage, bei „CSV“ oder „Excel“ entsteht eine Datei auf deinem Computer. Es wird nichts an uns oder Dritte übermittelt, und die Erweiterung speichert keine Tabelleninhalte.

Was gespeichert wird

Nur deine Einstellung für das CSV-Format (automatisch, Komma oder Semikolon), lokal in deinem Browser mit chrome.storage.local. Beim Deinstallieren wird sie entfernt.

Berechtigungen

  • activeTab: vorübergehender Zugriff auf den aktuellen Tab nach Klick auf das Symbol
  • scripting: um die Tabellenerkennung in diesem Tab auszuführen und eine Tabelle hervorzuheben
  • storage: um deine CSV-Einstellung zu speichern

Diese Website

Diese Website wird über GitHub Pages (GitHub Inc., USA) bereitgestellt. Beim Aufruf kann GitHub technische Daten wie deine IP-Adresse verarbeiten, um die Seite auszuliefern. Details in der Datenschutzerklärung von GitHub. Wir setzen auf dieser Website keine Cookies und keine Analyse-Tools ein.

Änderungen

Falls künftige Versionen Daten anders verarbeiten (z. B. Lizenzprüfung für kostenpflichtige Funktionen), wird diese Erklärung vorher aktualisiert.
