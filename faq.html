How to copy a table from a website into Excel, CSV or Google Sheets

A free way to get any web table into a spreadsheet in one click, with numbers that stay numbers.

Add TableDrop to Chrome – free

Step by step

  1. Install TableDrop from the Chrome Web Store and pin it to your toolbar.
  2. Open the page with the table, for example a Wikipedia article, a statistics page or a report.
  3. Click the TableDrop icon. It lists every table on the page. Hover a table in the list to jump to it on the page.
  4. Choose an export: Copy (paste into Excel or Google Sheets), CSV, Excel (.xlsx) or MD (Markdown).

Frequently asked questions

How do I copy a table from a website into Excel?

Click the TableDrop icon, pick the table and click Copy, then paste into Excel. Or click Excel to download a ready .xlsx file with a bold header row, frozen first row and filters.

How do I export an HTML table to CSV?

Click CSV next to the table. The file uses the separator and decimal format of your language (comma in English, semicolon with decimal comma in German and many European languages), so it opens correctly in Excel. You can change this at the bottom of the TableDrop popup.

How do I get a web table into Google Sheets?

Click Copy and paste into Google Sheets. Every value lands in its own cell.

Why do numbers turn into text or wrong values in Excel?

Web pages format numbers for reading: 1,420.50 or 1.420,50, $ and € signs, percent, or negatives in brackets like (300). Excel often reads these as text, or mixes up the decimal separator, so "1,420" can become 1.42. TableDrop recognizes these formats per column and exports real numbers. Dates, version numbers and codes like zip codes stay text.

Can I copy a web table as Markdown?

Yes. Click MD to copy the table as a Markdown table for Notion, GitHub, Obsidian or documentation. Number columns are right-aligned.

Which tables does TableDrop find?

Regular HTML tables, including merged cells, and modern web-app tables built as accessible grids. Tables drawn as images or on a canvas, and tables inside embedded frames, are not detected. If a table loads after the page, close and reopen TableDrop.

Why doesn't TableDrop work on some pages?

Chrome doesn't allow extensions on its own pages (chrome://), on the Chrome Web Store and in PDF files.

Is it free?

Yes. Copy, CSV, Excel and Markdown are all free, with no account and no sign-up.

Does TableDrop send my data anywhere?

No. TableDrop runs only when you click its icon, on the current tab, and processes tables in your browser. Nothing is sent to any server. Details in the privacy policy.
